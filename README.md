# Gotta Class 'Em All

An interactive Pokédex that teaches Object-Oriented Programming in Java through Pokémon.
CS3101 OOPS Illustration Assignment · SE24UCSE225

**Live site:** https://ritvikm57.github.io/oop-pokedex/

- `index.html`: the interactive site (classes & objects, encapsulation, inheritance, abstraction, polymorphism, overloading, interfaces, IS-A vs HAS-A, evolution ≠ inheritance, quiz)
- `PokedexOOP.java`: the runnable Java behind every example

```bash
javac PokedexOOP.java && java PokedexOOP
```

Pokémon names and artwork belong to Nintendo / Game Freak / The Pokémon Company; sprites from the PokeAPI sprite collection. Used for non-commercial teaching only.
